**რა შეიცვალა ძველი სახელმძღვანელოდან.** გაყინული ორიგინალი ([`docs/legacy/05-tutorial-building-a-bot.md`](./legacy/05-tutorial-building-a-bot.md)) ასწავლიდა **ბირჟათაშორის perp–perp** გარიგებას, როგორც მთავარს. ღრმა მიმოხილვამ აჩვენა, რომ ძირითად აქტივებზე ეს გარიგება სტრუქტურულად მწირია (ხარჯების შემდეგ შეიძლება ფული *დაკარგოს*), ამიტომ ეს ახალი ვერსია წინ სწევს **cash-and-carry**-ს — გარიგებას, რომელიც რეალურად აგროვებს funding-ის *დონეს* — და აქვეითებს ბირჟათაშორის მიდგომას შეზღუდულ სტრატეგია #2-მდე. საყრდენი საბაზრო/API ფაქტები ხელახლა გადამოწმდა ბირჟის ოფიციალურ დოკუმენტაციასთან **2026-07-18 (v0.6 round)** და **2026-07-19 (v0.7 round — იზოლირებული მარჟის შევსება, პოზიციის რეჟიმი, გასაღებების მართვის/fence endpoint-ები, SQLite-ის მდგრადობა)** თარიღებში (ნორმატიული endpoint-ები + მათი წყაროები მოცემულია §spec §4/§4.1/§4.2 (Profiles §1/§2/§3)-ში და მიმოხილვის ჩანაწერებში; ჩათვალეთ ბირჟის API ციკლზე ძველი ნებისმიერი ფაქტი ხელახლა გადასამოწმებლად). სწავლების ტონი შენარჩუნებულია; მიდგომა და ფაქტები დადგენილია.
