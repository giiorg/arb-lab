## მოქმედების არეალი და დაშვებები

პირველ რიგში წაიკითხეთ ეს ბლოკი — ის საზღვრავს ყველაფერს, რაც ქვემოთ არის მოცემული.

| დაშვება | MVP არჩევანი | რატომ არის მნიშვნელოვანი |
|---|---|---|
| **კონტრაქტის ტიპი** | **მხოლოდ წრფივი USDⓈ-M / USDT-მარჟირებული perp-ები** | თანაბარ-ბაზიანი დელტა-ნეიტრალობის მათემატიკა ითვალისწინებს წრფივ ანაზღაურებას. შებრუნებულ (COIN-M) perp-ებს აქვთ `1/P` ანაზღაურება არანულოვანი გამათი და ეს მათემატიკას დაარღვევდა (§spec C6). |
| **პოზიციის რეჟიმი** | **One-way რეჟიმი** (ერთი წმინდა პოზიცია სიმბოლოზე) | ბირჟა აკეთებს სიმბოლოზე *ყველა* სტრატეგიის რისკის (exposure) ნეტინგს. ძრავა უზრუნველყოფს ექსკლუზიურ უფლებას (lease) თითო `(account, venue, symbol)`-ზე — MVP-ში არ ხდება სტრატეგიებს შორის ნეტინგი (§spec §5.1). |
| **მარჟის უზრუნველყოფა** | **მხოლოდ USDT ან USDC** | ამის მიზეზია Oct-2025-ის USDe local-mark ჩავარდნა. არანაირი ეგზოტიკური stablecoin-ები, LST-ები ან შემოსავლიანი მარჟა. |
| **შენახვა** | **ბირჟაზე, მცირე ზომა, ლიმიტები თითო ბირჟაზე ≤~20–30%** | ბირჟის რისკის შეგნებული, დოკუმენტირებული მიღება პროდუქტის გასაშვებად. ბირჟის გარეთ settlement (OES) გაფართოების გზაა და არა MVP-ის მოთხოვნა (§spec §7.2). |
| **დრო** | **ბირჟის სერვერის დრო ავტორიტეტულია** | თქვენი ლოკალური საათი მხოლოდ დაყოვნების/სიახლისთვისაა და არასდროს funding-boundary გადაწყვეტილებებისთვის (§spec §3.5). |
| **ფული** | **მასშტაბირებული მთელი რიცხვი `fixedpoint`, არასდროს `float64`** | დეტერმინიზმი, დამრგვალების ცდომილების გარეშე, განმეორებადი ბექ-ტესტები. ყველა ფასი/ზომა/notional/განაკვეთი განზომილებიანი ტიპებია (§spec §3.6). |
| **სასწავლო ბირჟები** | **Binance + Bybit**, მაგალითად majors (BTC/ETH) | აგებულია N-ბირჟისთვის მზად (N-venue-ready) ერთი ადაპტერის მიღმა (§spec §4). |
