C · One dense console + drill-downs

A single top bar and one long scrolling console that answers "what's going on" without navigating. Everything else is a drill-down opened from it (click a symbol → detail route). Fewest places to be lost; best on a phone.

dense mobile-first 4 nav items

My recommendation: A, with one idea borrowed from C — a persistent top strip of status tiles (venues, equity, open packages, alerts) that stays visible on every screen, so "what's going on" is never more than a glance, and the sidebar collapses to a bottom bar on mobile. B is conceptually the most honest about where this project actually is, but a mode switch is a wall you pay for on every navigation, and the same honesty can be delivered by a single prominent Verdict panel inside A's Evidence section.
