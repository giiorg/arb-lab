ლიკვიდაცია, მარჟა და ADL

Cash-and-carry პოზიცია დელტა-ნეიტრალურია: long spot, short perp, თანაბარი ზომით. ნეიტრალური არ ნიშნავს უსაფრთხოს. perp leg-ს აქვს ბერკეტი და მკვეთრი ზრდისას მისი ლიკვიდაცია შეიძლება მოხდეს მაშინაც კი, როდესაც spot leg ზუსტად იმავე რაოდენობით იგებს — რადგან ეს ორი leg სხვადასხვა საფულეშია და ლიკვიდაციის ძრავა მხოლოდ ერთ მათგანს უყურებს.

გადამრჩენი მარჟა მოქმედებაა და არა ბუფერი

ინტუიციური გამოსავალი — ანგარიშზე თავისუფალი ფულის შენახვა — იზოლირებული მარჟის პირობებში არ მუშაობს. იზოლირებული ლიკვიდაციის ძრავა ვერ ხედავს საფულის თავისუფალ ბალანსს. ძრავისთვის იქვე მდებარე მარჟა არარსებული მარჟაა. core §7.1

ამიტომ გადარჩენა არის აქტიური add-margin API გამოძახება, რომელსაც მარჟა შეაქვს პოზიციაში, ბირჟაზე წინასწარ განთავსებული რეზერვიდან. ის წინასწარ უნდა იყოს განთავსებული, რადგან რეაქტიული ტრანსფერები spot-დან futures-ზე მიუწვდომელია ზუსტად იმ სტრესის დროს, როცა ისინი გჭირდება, და მას აქვს დაჯავშნილი rate-limit ბიუჯეტი, რათა არ მოხვდეს რიგში რუტინული ტრაფიკის უკან. core §7.1 tutorial §6.2

და თუ შევსება ძალიან ნელია

სათადარიგო ვარიანტია PackageDelever — ორივე leg-ის შემცირება, ჯერ perp-short-ის ხარჯზე, რაც შეკვეცის პროცესში პაკეტს ნეიტრალურს ტოვებს. ეს გამიზნულად არ არის ექსპოზიციის შემცირების ჩვეულებრივი გზა: პაკეტი ჯერ კიდევ ჰეჯირებულია, ამიტომ მხოლოდ ერთი leg-ის შემცირება შექმნიდა დაუცველ (naked) leg-ს იმ მკვეთრი ზრდის შუაგულში, რომელმაც საგანგებო მდგომარეობა გამოიწვია. core §7.1 core §5.3

ADL — ჰეჯი, რომელიც შენ თვალწინ იშლება

Auto-deleveraging არ არის უბრალო სქოლიო. 2025 წლის ოქტომბერში ბირჟებმა იძულებით დახურეს მომგებიანი short leg-ები, რამაც დესკები ღია (naked) long პოზიციით დატოვა ბაზარზე, რომელიც ჯერ კიდევ ეცემოდა. ჰეჯი მოხსნა ბირჟამ, ყველაზე ცუდ მომენტში, დაუკითხავად. core P3 tutorial §6.2

აქ Cash-and-carry-ს აქვს ერთი ვიწრო, მაგრამ რეალური უპირატესობა: spot leg არ ექვემდებარება ADL-ს და არ ჩამოგერთმევათ იმ პოზიციის პირობებში, რომელსაც ეს პროექტი იყენებს, ამიტომ მთლიანი პოზიცია არასდროს იკარგება ერთდროულად. მაგრამ იძულებით დახურული short მაინც ტოვებს მიმართულების ექსპოზიციას, რომელიც უნდა აღმოაჩინოთ პრივატული ADL მოვლენიდან და დაუყოვნებლივ შეამციროთ. core §4.1

აქ არის ერთი დეტალი, რომელიც სპეციფიკაციის პირველ დრაფტში არასწორად იყო და ეს კარგად ასახავს, თუ რამდენად სპეციფიკურია ეს სფერო: ნულამდე ADL-ირებული perp-ის ხელახლა ჰეჯირებისთვის, თქვენ უნდა განათავსოთ ჩვეულებრივი short — და არა reduce-only. Reduce-only-ის არ შეუძლია პოზიციის გახსნა, ამიტომ ბირჟა მას უარყოფს. დაუცველი (naked) spot long-ის გასანულებლად კი ჩვეულებრივ sell-ს ათავსებთ, რადგან reduceOnly spot-სთვის არცერთ ბირჟაზე არ არსებობს. tutorial §6.2 core §5.3
