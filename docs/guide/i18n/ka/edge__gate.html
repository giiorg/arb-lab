ეკონომიკური ზღურბლი

მხოლოდ რიცხვი ვერ გეტყვით, ღირს თუ არა ამის აშენება. მან რაღაცას უნდა აჯობოს. ეს „რაღაც“ არის თითქმის ურისკო მინიმუმი — რასაც იგივე კაპიტალი გამოიმუშავებს ტოკენიზებულ T-bills-ში მოთავსებისას, დაახლოებით 4.6%. core §2.1

ამ ბენჩმარკთან დაკავშირებით ორი რამ განზრახ არის ასე. მას თითქმის ურისკო ეწოდება, რადგან ის მაინც შეიცავს სმარტ-კონტრაქტის, კონტრაგენტის და დეპეგის რისკს, ამიტომ იგი კორექტირებულია haircut-ით და არა აღებული ნომინალური ღირებულებით. გარდა ამისა, ის არის თარიღის მქონე, წყაროზე დაფუძნებული და ვერსიებით კონტროლირებადი მონაცემი — სადაც წყარო, დროის ნიშნული, წვდომის ხარჯი, ლიკვიდურობის და კონტრაგენტის haircut-ები დაფიქსირებულია — და არასდროს არის ხისტად ჩაწერილი 4.6%-იანი მუდმივა. აქ მოყვანილი რიცხვი საილუსტრაციოა; რეალური მაჩვენებელი ის არის, რასაც მიმდინარე ვერსია ამბობს. core §2.1

რატომ იყინება ზღვრები ტესტის გაშვებამდე

კარიბჭის რიცხვითი ზღვრები — საწინააღმდეგო მოძრაობის ზომა, დაყოვნება, ფანჯრის ხანგრძლივობა, რეჟიმის სეგმენტაცია, სარეზერვო ბენჩმარკი, ვარდნის ზედა ზღვარი, სანდოობის დონე, მოსალოდნელი utilization — არის წინასწარ დარეგისტრირებული, ვერსიის მქონე კალიბრაციის არტეფაქტი. ის იქმნება და მტკიცდება საპრომოციო შერჩევის შეფასებამდე უფრო ადრე, და შეიცავს გაყინულ მონაცემთა ნაკრებს გამოყოფილი (holdout) იდენტიფიკატორებით, სქემითა და კონტენტის ჰეშით, დასაბუთებასა და დამტკიცების ისტორიას. ნებისმიერი მათგანის შეცვლა იწვევს ახალი ვერსიის შექმნას და ტესტის სრულად თავიდან გაშვებას. core §8

ეს ბიუროკრატია არ არის, ეს არის ერთადერთი თავდაცვა იმ მარცხისგან, რომელიც კლავს ბექ-ტესტირებულ სტრატეგიებს: ზღვრის მორგება მანამ, სანამ შედეგი მისაღები არ გახდება. სპეციფიკაცია პირდაპირ ამბობს, თუ რა არ გვეხმარება — ორი დამოუკიდებელი იმპლემენტაციის თანხვედრა ერთსა და იმავე არტეფაქტზე ამტკიცებს დეტერმინისტულობას და არა დამოუკიდებლობას. მხოლოდ მართვის წესები (წინასწარ დარეგისტრირებული, holdout-გაყინული) უშლის ხელს სასურველ შედეგამდე მორგებას. core §8

სოლო ოპერატორისთვის, მექანიკურად გამოყვანილი ზღვრები წარმოადგენს სტანდარტულ მართვას. კონკრეტული დამოუკიდებელი დამმტკიცებელი საჭიროა მხოლოდ მაშინ, თუ ოპერაციაში რეალურად არიან ჩართული სხვა კადრები — სპეციფიკაცია უარს ამბობს, თავი ისე მოგვაჩვენოს, თითქოს მეორე ადამიანი არსებობს. core §8 core §9

ნეგატიური რეჟიმი არ ნიშნავს ჩაჭრას

ერთი ნიუანსი, რომლის სწორად ჩამოყალიბებასაც გადახედვის ერთი რაუნდი დასჭირდა. ნეგატიური funding რეჟიმის შიგნით hurdle-ის მოთხოვნა შეუსრულებელია — სტრატეგია, რომელიც სწორად იკავებს თავს, იქ დაახლოებით ნულს გამოიმუშავებს, და ეს არის სწორი ქცევა და არა მარცხი. core §2.4

შესაბამისად, რეჟიმის კლასიფიკაციას ენიჭება პრიორიტეტი: ნეგატიურად კლასიფიცირებული ფანჯრები ფასდება სწორი თავშეკავებითა და შეზღუდული ზარალით განსაზღვრულ სარეზერვო ბენჩმარკთან მიმართებაში, მაშინ როცა მხოლოდ არა-ნეგატიური ან შერეული ფანჯრები, პლუს სრული შერჩევა, ექვემდებარება hurdle-ს — ისიც წმინდა ამონაგების სანდოობის ქვედა ზღვრის და არა წერტილოვანი შეფასების მიხედვით. core §8
