რეალური ხარჯი

უპირატესობა თითოეულ settlement-ზე მხოლოდ რამდენიმე საბაზისო პუნქტია. ხარჯი იფარება წინასწარ და სრულად. ხარჯის ნაწილის მცირედით არასწორად გათვლაც კი მომგებიან სტრატეგიას წამგებიანად აქცევს, ამიტომაც სპეციფიკაცია ამ საკითხზე ყველაზე მკაცრია.

spot საკომისიოები არ არის perp საკომისიოები

spot taker საკომისიოები საგრძნობლად მაღალია, ვიდრე perp — დაახლოებით 0.075–0.10% დაახლოებით 0.05%-ის წინააღმდეგ. მათი მოთხოვნა უნდა მოხდეს ცალ-ცალკე, თითოეული leg-ისა და ბირჟისთვის. cash-and-carry გარიგებისთვის perp round trip მაჩვენებლის ხელახლა გამოყენება ამცირებს იმ leg-ის ხარჯს, რომელშიც რეალურად ყველაზე მეტს იხდით. core §2.4

და ხარჯის მოდელს აქვს ზუსტად ერთი ჭეშმარიტების წყარო: საკომისიოები მიიღება პროგრამულად მოთხოვნილი, თითოეული leg-ისა და ბირჟის განაკვეთებს დამატებული გაზომილი slippage მოდელით. არავითარი ხისტად გაწერილი საკომისიოს მუდმივები და არანაირი რიცხვის მეორე ასლი, რომელიც სხვა მოდულში ინახება. core §2.4

round trip და რას გულისხმობს ის

VIP0 taker განაკვეთების პირობებში, round trip არის spot ორჯერ ~0.10%-ად, perp ორჯერ ~0.05%-ად და ოთხი leg ~0.02% slippage-ით — ჩავთვალოთ, რომ ეს notional-ის 0.34–0.38%-ია. საბაზისო +0.01%/8h funding-ის ფონზე, ეს ნიშნავს დაახლოებით 12–13 დღეს მხოლოდ უზარალობის წერტილამდე მისასვლელად და დაახლოებით ოთხ კვირას hurdle-ის გადასალახად. უხვ +0.02%/8h რეჟიმშიც კი დაახლოებით ექვსი დღეა საჭირო, სანამ მოგების პირველი ცენტი გაჩნდება. core §2.4

რაც იწვევს შედეგს, რომელიც აყალიბებს მთლიან სტრატეგიას: პოზიციის შენარჩუნების მინიმალური დრო კვირებით იზომება — ზუსტად იმავე მასშტაბით, როგორიცაა უარყოფითი funding რეჟიმები, რომელთა თავიდან აცილებასაც ცდილობთ (მათ შორის დოკუმენტირებული 46-დღიანი სერია). შესაბამისად, რეჟიმის მდგრადობა მოგება / ზარალის მთავარი მამოძრავებელი ფაქტორია და არა tail რისკი. სწორედ ამიტომ, პოზიციაში შესვლა და გამოსვლა ეფუძნება პროგნოზს ჰისტერეზისის ზოლით და არა მიმდინარე funding rate-ის spot მაჩვენებელს. core §2.4

utilization უპირატესობის ნაწილია

სანამ სტრატეგია გამართლებულად არის შეჩერებული, კაპიტალი ბირჟაზე თითქმის ვერაფერს გამოიმუშავებს — ხოლო hurdle ამის მიუხედავად მაინც განაგრძობს ზრდას სხვაგან. ამიტომაც, მთავარი მაჩვენებელი ყოველთვის პოზიციაში ყოფნის მოსალოდნელი დროით უნდა იყოს გამოსახული და არასდროს პოზიციაში ყოფნის მიმდინარე განაკვეთით. მთლიანი 8% carry 60% utilization-ის პირობებში არის ~4.8%-იანი ბიზნესი საოპერაციო რისკამდე და არა 8%-იანი. core §2.4 core §2.1

მნიშვნელი და მირაჟი

$100,000-ის short perp პოზიციით +0.01%/8h პირობებში, თქვენ იღებთ $10-ს ყოველ 8 საათში — $30-ს დღეში, რაც notional-ზე წლიურ დაახლოებით 10.95%-ს შეადგენს. თუ მარჟის სახით მხოლოდ $10,000 შეიტანეთ, იგივე $30 უკვე აღიქმება, როგორც დაახლოებით 110% APR მარჟაზე. tutorial §1.5

ეს რიცხვი მირაჟია. ის უგულებელყოფს ლიკვიდაციის რისკს, რომელიც მის მისაღებად აიღეთ. შემოსავლიანობა გამოითვლება სრულად გამოყოფილ კაპიტალზე — spot ძირითადი თანხა, perp მარჟა, გადარჩენის მარჟა, საკომისიოსა და slippage რეზერვი, შებოჭილი ნაშთი — და არასდროს უბრალოდ შეტანილ მარჟაზე, არც თითოეული leg-ის კაპიტალის ქვედა ზღვარზე. მომდევნო გვერდზე არსებული კალკულატორი იყენებს ზუსტად ამ მნიშვნელს, რის გამოც მისი პასუხები ნაკლებად მიმზიდველია იმათთან შედარებით, რასაც სხვაგან წაიკითხავთ. core §2.1 core §2.2
