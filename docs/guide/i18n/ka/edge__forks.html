Milestone 2 იმისთვის არსებობს, რომ ერთ კითხვას იაფად გაეცეს პასუხი, სანამ OMS, უსაფრთხოების ბირთვი, fence და actuator შეიქმნება: მოაქვს ამას ფული? სპეციფიკაციის საკუთარი არითმეტიკა პროგნოზირებს, რომ პასუხი უარყოფითია — დაახლოებით 3.4% 60% utilization-ის პირობებში ~4.6% hurdle-თან შედარებით, BTC-სთვის VIP0 საკომისიოებით. core §12 tutorial §3.9

ეს არის კარიბჭე, რომელიც მუშაობს ისე, როგორც ჩაფიქრებული იყო და ეს არ არის მოულოდნელობა. განშტოებები დაიწერა ახლა, წინასწარ, სწორედ იმისთვის, რომ გადაწყვეტილება არ მივიღოთ მომენტალური იმედგაცრუების ფონზე. core §12

(a) Maker spot შესვლა მიმართეთ დროში არაკრიტიკული leg როგორც maker ორდერი. ის დაახლოებით ანახევრებს round-trip ხარჯს — რაც უფრო დიდი ეფექტია, ვიდრე უმეტესი მოდელირებული გაუმჯობესება. ის ეწინააღმდეგება taker-IOC leg-რისკის მანდატს, ამიტომ ის არის არჩევითი, დოკუმენტირებული ტაქტიკა, რომელსაც აქვს fill-თაიმაუტის შემთხვევაში taker-ზე გადართვის მექანიზმი, და არასოდეს არის ჩუმად გააქტიურებული ნაგულისხმევი ვარიანტი.
(b) რეჟიმების შერჩევა გააფორმეთ გარიგება მხოლოდ გაზომილად დადებით რეჟიმებში და დათანხმდით უფრო დაბალ utilization-ს. უფრო მაღალი საშუალო განაკვეთი, რომელიც მიღწეულია მეტი უმოქმედო დროის ხარჯზე.
(c) ალტკოინების / დისლოკაციის ნიშა სტრატეგია #2 მოდის იმაზე ადრე, ვიდრე დაგეგმილი იყო — იმ დამატებით რისკებთან ერთად, რაც მას თან ახლავს.
(d) სწავლის საფასური შეგნებულად მიიღეთ sub-hurdle ამონაგები, როგორც პლატფორმის აშენების ფასი. ეს ლეგიტიმური არჩევანია, სანამ ის გააზრებულად არის მიღებული და არა უბრალოდ მოვლენების დინებას მიყოლით.
