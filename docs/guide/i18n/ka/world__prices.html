Mark, index, last

ერთი და იმავე ინსტრუმენტისთვის ერთსა და იმავე მომენტში სამი ფასი არსებობს და არასწორის გამოყენება შეუმჩნეველი, ძვირადღირებული შეცდომაა.

Last ბოლო გარიგება ამ ბირჟაზე. ხმაურიანი და მანიპულირებადი ნებისმიერის მიერ, ვისაც სურს ერთი ცუდი გარიგების დაფიქსირება.
Index spot ფასების კალათა რამდენიმე ბირჟაზე. „ჭეშმარიტი“ საყრდენი, რომლის გადაადგილებაც რთულია.
Mark index-ისა და basis-ისგან მიღებული გასაშუალოებული ფასი. სწორედ ის მართავს ლიკვიდაციას და funding-ს.

თქვენი მიმდინარე funding-ის შეფასება მიბმულია mark-ზე და არა last-ზე. tutorial §1.6

რატომ ჩნდება ეს არქიტექტურაში

თუკი mark მართავს ლიკვიდაციას, მაშინ თქვენი დისტანცია ლიკვიდაციამდე იცვლება mark-ის მოძრაობასთან ერთად — და არა მხოლოდ მაშინ, როცა რამე ხდება თქვენს ანგარიშზე. ძრავა, რომელიც ლიკვიდაციამდე დისტანციას ხელახლა ითვლის მხოლოდ პოზიციისა და მარჟის მოვლენებზე დაყრდნობით, მშვიდად იჯდება მანამ, სანამ ბაზარი მიიწევს იმ ფასისკენ, რომელიც მას დახურავს. tutorial §6.2

ამიტომ ლიკვიდაციამდე დისტანცია ხელახლა გამოითვლება mark-ის ყოველი ახალი განახლებისას, ხოლო შეყოვნებული mark-ის ნაკადი თავისთავად საგანგებო სიტუაციაა: ის ბლოკავს ახალ გახსნებს და ახდენს ესკალაციას, გადადის ბირჟის REST mark ზედაპირზე, და თუ ორივე ბრმა რჩება ბიუჯეტის ამოწურვის შემდეგ, აქტიურდება წინასწარ ავტორიზებული de-lever ან დახურვა. core §7.1 core §6
